# Plan 4a — Legacy Block Converter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 18 legacy Pediment presentation blocks with core blocks and named styles on any site — through one converter service that the MCP tool, a wp-admin tab and WP-CLI share — and stop new content from getting legacy blocks.

**Architecture:** `Pediment\Convert\Converter` walks parsed blocks and hands each legacy block to a mapper (`Pediment\Convert\Mappers\*`, one class per block or parent/child pair). Mappers build parsed-block arrays through `Build` (exact core `save()` markup) and the converter serializes them with `serialize_blocks()`. `PostConverter` applies it to stored posts (revision first, dry-run diff, content-rule gate) and `PatternFiles` to theme pattern files; the `pediment/convert-legacy` ability, the "Convert legacy blocks" settings tab and `wp pediment convert` call these two services. Eleven new plugin default styles carry the looks; a `register_block_type_args` filter hides the legacy blocks from the inserter.

**Tech Stack:** PHP 8.1, WordPress 6.9 (block parser/serializer, Abilities API, block style variations), PHPUnit via wp-env, Node 20 (`client-kit` validate-blocks runtime for WordPress 6.9 and 7.0), Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-14-core-blocks-mcp-design.md` (§2 design layer, §3 MCP tools, §4 migration, §5 testing, §6 documentation). Roadmap: `docs/superpowers/plans/2026-10-14-roadmap.md`. Binding decisions: `.context/plan4-decisions.md` (local, gitignored). Research notes (local, gitignored): `.context/plan4-research-blocks.md` (mapping templates, style drafts), `.context/plan4-research-sites.md` (client-site usage).

## Global Constraints

- Builds on Plans 1–3 on branch `bergjs/elementor-pediment-necessity` (PR #117, not merged). `Requires at least: 6.9`. PHP 8.1, `declare(strict_types=1);`, `ABSPATH` guard, text domain `pediment`, `_doing_it_wrong` version `'4.0.0'`.
- Converter code lives in `plugin/src/Convert/` (namespace `Pediment\Convert`; mappers in `Pediment\Convert\Mappers`). It reads parsed markup only: no `WP_Block_Type_Registry` lookup of a legacy block and no block.json defaults (`parse_blocks()` returns stored attributes only), so it keeps working after Plan 6 deletes the legacy registrations. Every mapper applies the legacy defaults itself.
- Converted markup is built from parsed-block arrays (`Build`) and `serialize_blocks()`, never by concatenating serialized block strings. Text from legacy attributes goes through `Attrs::rich()` (`wp_kses_post()`, no `<!--`), URLs through `esc_url()`, alt text and class names through `esc_attr()`.
- Every mapper output passes `Policy::check()` with zero errors and `validate-blocks` on WordPress 6.9 and 7.0. A fixture pair in `plugin/tests/phpunit/Convert/fixtures/` proves it: PHPUnit compares the exact output, `node tools/validate-convert-fixtures.mjs` validates every `*.expected.html` (CI job `validator`). Every expected file in this plan was generated by the code in this plan and validated on both lines before the plan was written.
- Copy fixture files byte for byte. Input fixtures contain no backslash-u escapes on purpose. `feature-grid.expected.html` is the only file with backslash-u sequences (`serialize_block_attributes()` writes `--` that way); Task 3 shows how to write it safely.
- Ability names match `^[a-z0-9-]+/[a-z0-9-]+$`. The ninth ability is `pediment/convert-legacy`; MCP tool name `pediment-convert-legacy`. `permission_callback` returns a plain `bool`. Never set `meta.public` or `meta.mcp.public`. Every `WP_Error` an ability returns lists each problem in its message (the MCP Adapter shows the message only).
- Everything multilingual goes through `Pediment\Language\LanguageRegistry::provider()`; never call `pll_*` or WPML filters outside `plugin/src/Language/`.
- Content seeding stays declarative: patterns change through `wp pediment convert --patterns`, never by writing pages with `wp post create` / `wp post update`.
- The root wp-env port varies per workspace (55280 in `cancun-v1`) and permalinks are plain: read the URL with `npx wp-env run cli wp option get siteurl` and use `?rest_route=` URLs. Tests: `npx wp-env run tests-wordpress --env-cwd=wp-content/plugins/pediment-ai ./vendor/bin/phpunit --filter <Name>`; Polylang suite: add `-c phpunit-polylang.xml.dist`. Lint: `composer lint -d plugin` (0 errors; warnings do not fail). Kit tests: `npm run test:kit`. Fixture validation: `node tools/validate-convert-fixtures.mjs` (first run per WordPress line installs a ~700 MB runtime into `~/.cache/pediment/validator`).
- Playwright e2e may be tried in this workspace (`npm run e2e -- convert-legacy`); the suite ran here during Plan 3's final wave. If it cannot start, check the same assertions with a headless Playwright probe against the dev site and say so in the task report.
- npm: never run `npm install` with the local npm 11 in tracked package dirs; use `npx -y npm@10 …`. Stage files by name; conventional commits, summary ≤ 60 characters; never push.

## Decisions taken in this plan

From `.context/plan4-decisions.md` (binding):

- C1 Mappings follow the validated research templates; no `tile` style; `media-row` sits on `core/media-text`.
- C2 Eleven new plugin default styles: media-card, stat, steps, panel, quote-card, accordion, media-row (required) and pull-quote, framed, logos, prose (parity); each passes StyleValidator and appears in a validated fixture.
- C3 One mapper class per legacy block or parent/child pair; a lone child converts too; a block without a mapper stays and is reported as unmapped.
- C4 Output comes from block arrays and `serialize_blocks()`; attribute text is escaped the way core stores it.
- C5 Plain classes stay on the outer block; `is-style-*` classes stay only when registered for the target block, otherwise they are dropped and noted per page.
- C6 Converted output passes `Policy::check()` with zero new errors (existing errors are reported, not fixed); fixture per mapper, PHPUnit equality, CI validation on 6.9 and 7.0.
- C7 Revision before the update, then update, clear `InvalidBlockLog`, return the revision id (never an autosave); dry run returns a per-post diff and changes nothing.
- C8 Scope: pages, posts, synced patterns and DB templates/template parts in every language (unscoped language query); report per post id and type.
- C9 One service behind the ability (ids or all, dry_run default true, capability checks, destructive), the wp-admin screen (preview, confirm with nonce and capability) and `wp pediment convert [--dry-run] [--patterns=<dir>]`.
- C10 Legacy blocks get `supports.inserter = false` through `register_block_type_args`; they still render; no block.json edits.
- C11 The plugin's and client-template's own patterns are converted with the CLI; the fixture client theme has no legacy blocks (checked).
- C12 `upsert-style` saves a first revision on create; design-layer.md documents `:where()` and whole-object replacement; an image upload tool goes to the roadmap only.
- C13 Nine abilities: every test and doc that pins the list is updated.

Further decisions this plan takes (review them):

- D1 Converted markup uses the block editor's serializer layout (newline after an opening comment, blank line between inner blocks), so diffs and converted pattern files stay readable. Validated in that form.
- D2 A legacy block that rendered nothing, and a legacy container left without children, is removed and noted ("pediment/faq-item: rendered nothing, removed").
- D3 A kept legacy `is-style-*` class is added after the mapper's own style class (both stay), so the card or stat look is not lost.
- D4 Post reports carry `revision` (newest revision after the write, like write-page) and `restoreRevision` (the pre-conversion revision for rollback-page).
- D5 "New" content-rule errors are found by comparing messages without their block path, because paths shift when a block is removed.
- D6 Diffs are capped at 20 000 bytes per post.
- D7 The wp-admin screen is a "Convert legacy blocks" tab in Settings → Pediment Theme (the plugin's only admin page); it needs `manage_options` and `edit_theme_options`, converts exactly the previewed ids, and shows the result once.
- D8 `convert-legacy` is annotated destructive and idempotent, so core's Abilities REST route wants DELETE with string query values; `execute()` reads booleans with `rest_sanitize_boolean()`. Recorded as a WordPress trap.
- D9 The hero stat-card cover sets `isDark: false` also without an image, so the light stat card keeps dark text (validated).
- D10 `--patterns` swaps inline PHP and media placeholders for stand-ins during conversion and refuses to write a file whose inline PHP would not survive.
- D11 While converting `plugin/patterns/prose-article.php`, its three stale core blocks (flagged by validate-blocks) are re-saved in their current form.

## Review Focus

1. A legacy block nested inside another legacy block, or deep inside core containers, with an empty legacy sibling that gets removed: every level converts and the parent's `innerContent` stays aligned, so no inner block is lost or duplicated — Task 2 pins it (`ConverterTest::test_legacy_blocks_convert_at_every_depth_and_removed_ones_take_their_slot`).
2. Translated pages: on a Polylang site the converter finds and converts the pages of every language, even when the request is scoped to one language — Task 7 pins it (`ConvertLanguageTest`, Polylang suite).
3. A page whose other content already breaks a content rule (a literal colour set in the editor) still converts; only an error the conversion adds blocks the write, and it is named — Task 7 pins it (`test_existing_rule_errors_are_reported_but_do_not_block`, `test_a_conversion_that_adds_a_rule_error_is_not_written`).
4. Legacy blocks inside synced patterns and database template parts render on many pages: the scan finds them, converts them in place, and leaves the pages that reference them untouched — Task 7 pins it (`test_synced_patterns_and_template_parts_are_found_and_converted`).
5. Attribute text that holds HTML (links, `&amp;`, `<span class="accent">`, `<strong>`) keeps its markup, but a `<script>` or a block delimiter inside an attribute never becomes live markup or a new block — Tasks 2 and 4 pin it (`test_attribute_html_is_kept_but_cannot_become_live_markup_or_a_block`, `test_answer_html_survives_as_markup`).

```php
<?php

use Pediment\Design\DefaultStyles;
use Pediment\Design\StyleValidator;

class DefaultStylesTest extends WP_UnitTestCase {

	private function render_variation_css( string $markup ): string {
		wp_deregister_style( 'block-style-variation-styles' );
		wp_clean_theme_json_cache();
		do_blocks( $markup );
		$after = wp_styles()->get_data( 'block-style-variation-styles', 'after' );
		return is_array( $after ) ? implode( "\n", $after ) : '';
	}

	public function test_every_default_style_passes_the_validator(): void {
		$specs = DefaultStyles::specs();
		$this->assertCount( 18, $specs );
		foreach ( $specs as $spec ) {
			$this->assertSame( array(), ( new StyleValidator() )->validate( $spec ), $spec['slug'] );
		}
	}

	public function test_defaults_are_registered_with_style_data(): void {
		DefaultStyles::registerAll();
		$styles = WP_Block_Styles_Registry::get_instance()->get_registered_styles_for_block( 'core/group' );
		$this->assertArrayHasKey( 'card', $styles );
		$this->assertNotEmpty( $styles['card']['style_data'] );
	}

	public function test_card_renders_token_css(): void {
		DefaultStyles::registerAll();
		$css = $this->render_variation_css( '<!-- wp:group {"className":"is-style-card"} --><div class="wp-block-group is-style-card"><p>x</p></div><!-- /wp:group -->' );
		$this->assertStringContainsString( 'is-style-card--', $css );
		$this->assertStringContainsString( 'border-radius: var(--wp--custom--radius--md)', $css );
	}

	public function test_converter_styles_are_registered_for_their_blocks(): void {
		DefaultStyles::registerAll();
		$registry = WP_Block_Styles_Registry::get_instance();
		$expected = array(
			'core/group'      => array( 'stat', 'steps', 'panel', 'quote-card', 'logos', 'prose' ),
			'core/cover'      => array( 'media-card' ),
			'core/details'    => array( 'accordion' ),
			'core/media-text' => array( 'media-row' ),
			'core/quote'      => array( 'pull-quote' ),
			'core/image'      => array( 'framed' ),
		);
		foreach ( $expected as $block => $slugs ) {
			foreach ( $slugs as $slug ) {
				$this->assertArrayHasKey( $slug, $registry->get_registered_styles_for_block( $block ), "{$slug} on {$block}" );
			}
		}
	}

	public function test_media_row_css_reaches_the_media_text_image(): void {
		DefaultStyles::registerAll();
		$css = $this->render_variation_css( '<!-- wp:media-text {"className":"is-style-media-row"} --><div class="wp-block-media-text is-stacked-on-mobile is-style-media-row"><figure class="wp-block-media-text__media"></figure><div class="wp-block-media-text__content"></div></div><!-- /wp:media-text -->' );
		$this->assertMatchesRegularExpression( '/\.wp-block-media-text\.is-style-media-row--\d+>\.wp-block-media-text__media img\)\{border-radius:var\(--wp--custom--radius--md\)/', $css );
	}

	public function test_accordion_styles_the_open_details(): void {
		DefaultStyles::registerAll();
		$css = $this->render_variation_css( '<!-- wp:details {"className":"is-style-accordion"} --><details class="wp-block-details is-style-accordion"><summary>Q</summary></details><!-- /wp:details -->' );
		$this->assertStringContainsString( 'background-color: var(--wp--preset--color--surface-elevated)', $css );
		$this->assertMatchesRegularExpression( '/is-style-accordion--\d+\[open\]\)\{border-color:var\(--wp--preset--color--border-strong\)/', $css );
	}

	public function test_framed_puts_radius_and_shadow_on_the_img(): void {
		DefaultStyles::registerAll();
		$css = $this->render_variation_css( '<!-- wp:image {"className":"is-style-framed"} --><figure class="wp-block-image is-style-framed"><img src="x.jpg" alt=""/></figure><!-- /wp:image -->' );
		$this->assertMatchesRegularExpression( '/\.wp-block-image\.is-style-framed--\d+ img,[^{]*\)\{border-radius: var\(--wp--custom--radius--md\);box-shadow: var\(--wp--preset--shadow--medium\);/', $css );
	}

	public function test_pill_text_uses_the_surface_token(): void {
		$pill = null;
		foreach ( DefaultStyles::specs() as $spec ) {
			if ( 'pill' === $spec['slug'] ) {
				$pill = $spec;
			}
		}
		$this->assertNotNull( $pill );
		$this->assertSame( 'var:preset|color|surface', $pill['styles']['color']['text'] );
	}

	public function test_radius_tokens_exist(): void {
		wp_clean_theme_json_cache();
		$this->assertSame( '12px', wp_get_global_settings( array( 'custom', 'radius', 'md' ) ) );
		$this->assertSame( '999px', wp_get_global_settings( array( 'custom', 'radius', 'pill' ) ) );
	}
```

```php
	/**
	 * Style names registered for a block type: block style variations from the
	 * registry plus the styles the block type declares itself.
	 *
	 * @param string $block Block name.
	 * @return list<string>
	 */
	public static function registeredStyleNames( string $block ): array {
		$known = array_map( 'strval', array_keys( \WP_Block_Styles_Registry::get_instance()->get_registered_styles_for_block( $block ) ) );
		$type  = \WP_Block_Type_Registry::get_instance()->get_registered( $block );
		if ( $type && is_array( $type->styles ) ) {
			foreach ( $type->styles as $style ) {
				if ( isset( $style['name'] ) ) {
```

```php
 * Reads legacy block attributes and escapes them the way core stores them.

 * @package Pediment

/**
 * Attribute readers. parse_blocks() returns only the attributes a block stored, never the
 * block.json defaults, so every reader takes its default explicitly.

final class Attrs {

	/**
	 * A scalar attribute as a string.
	 *
	 * @param array  $attrs   Attributes.
	 * @param string $key     Key.
	 * @param string $fallback Value when the attribute is missing or not scalar.
	 */
	public static function string( array $attrs, string $key, string $fallback = '' ): string {
		$value = $attrs[ $key ] ?? $fallback;
		return is_scalar( $value ) ? (string) $value : $fallback;
	}

	/**
	 * A numeric attribute as an int (0 when missing).
	 *
	 * @param array  $attrs Attributes.
	 * @param string $key   Key.
	 */
	public static function int( array $attrs, string $key ): int {
		$value = $attrs[ $key ] ?? 0;
		return is_numeric( $value ) ? (int) $value : 0;
	}

	/**
	 * A RichText attribute as the HTML a core block stores: post-allowed tags
	 * only (the legacy render.php printed it through wp_kses_post() too) and
	 * no block delimiter, so attribute text can never open a block.
	 *
	 * @param array  $attrs Attributes.
	 * @param string $key   Key.
	 */
	public static function rich( array $attrs, string $key ): string {
		return self::html( self::string( $attrs, $key ) );
	}

	/**
	 * Escapes a RichText value (see rich()).
	 *
	 * @param string $value Value.
	 */
	public static function html( string $value ): string {
		return str_replace( '<!--', '&lt;!--', wp_kses_post( $value ) );
	}

	/**
	 * A URL attribute, escaped for an href or src.
	 *
	 * @param array  $attrs Attributes.
	 * @param string $key   Key.
	 */
	public static function url( array $attrs, string $key ): string {
		return esc_url( self::string( $attrs, $key ) );
	}

	/**
	 * Sets $key when $value is neither null nor ''.
	 *
	 * @param array       $attrs Attributes.
	 * @param string      $key   Key.
	 * @param string|null $value Value.
	 */
	public static function put( array $attrs, string $key, ?string $value ): array {
		if ( null !== $value && '' !== $value ) {
			$attrs[ $key ] = $value;
		}
		return $attrs;
```

```php
 * Builders for parsed core blocks whose HTML matches the block's save().
 *
 * @package Pediment

declare(strict_types=1);

namespace Pediment\Convert;

/**
 * Each method returns one parse_blocks()-shaped array. The HTML is what the
 * block editor's save() stores, in the editor's serializer layout (a newline
 * after the opening comment and before the closing one, a blank line between
 * inner blocks), so serialize_blocks() of the result passes block validation.
 * Text and URLs passed in must already be escaped (see Attrs).
 */
final class Build {

	/**
	 * A block without inner blocks.
	 *
	 * @param string $name  Block name.
	 * @param array  $attrs Comment attributes.
	 * @param string $html  Saved HTML.
	 */
	public static function leaf( string $name, array $attrs, string $html ): array {
		return array(
			'blockName'    => $name,
			'attrs'        => $attrs,
			'innerBlocks'  => array(),
			'innerHTML'    => "\n{$html}\n",
			'innerContent' => array( "\n{$html}\n" ),
		);
	}

	/**
	 * A block with inner blocks: $open, the inner blocks separated by blank
	 * lines, $close.
	 *
	 * @param string $name  Block name.
	 * @param array  $attrs Comment attributes.
	 * @param string $open  HTML before the inner blocks.
	 * @param array  $inner Parsed inner blocks.
	 * @param string $close HTML after the inner blocks.
	 */
	public static function container( string $name, array $attrs, string $open, array $inner, string $close ): array {
		$inner   = array_values( $inner );
		$content = array( "\n{$open}" );
		foreach ( $inner as $i => $unused ) {
			if ( $i > 0 ) {
				$content[] = "\n\n";
			}
			$content[] = null;
		}
		$content[] = "{$close}\n";
		return array(
			'blockName'    => $name,
			'attrs'        => $attrs,
			'innerBlocks'  => $inner,
			'innerHTML'    => implode( '', array_filter( $content, 'is_string' ) ),
			'innerContent' => $content,
		);

	 * Builds core/group. Reads tagName, align, className and a preset
	 * style.spacing.margin.bottom from $attrs.
	 *
	 * @param array $attrs Attributes.

	 * @param array  $attrs Attributes.

		$class = self::classes( isset( $attrs['align'] ) ? 'has-text-align-' . $attrs['align'] : '', (string) ( $attrs['className'] ?? '' ) );
		return self::leaf( 'core/paragraph', $attrs, '' === $class ? "<p>{$html}</p>" : "<p class=\"{$class}\">{$html}</p>" );
	}

	 * Builds core/heading. Level 2 is core's default and is not stored.

	 * @param int    $level Heading level.
	 * @param string $html  Escaped content.

	/**
	 * The class attribute value from class names; empty names are skipped.

	 * @param string ...$names Class names.
```

```php
/**
 * Rewrites legacy Pediment blocks in block markup to core blocks.
 *
 * @package Pediment

declare(strict_types=1);

namespace Pediment\Convert;

use Pediment\Content\Policy;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * Walks parsed blocks; every legacy block with a mapper is replaced (at any
 * depth), every other block is kept and walked. Output comes from
 * serialize_blocks(), never from string concatenation of user content.
 */
final class Converter {

	/**
	 * Mapper per legacy block name.
	 *
	 * @var array<string,Mapper>
	 */
	private array $mappers = array();

	/**
	 * Constructor.
	 *
	 * @param list<Mapper> $mappers Mappers.
	 */
	public function __construct( array $mappers ) {
		foreach ( $mappers as $mapper ) {
			foreach ( $mapper->names() as $name ) {
				$this->mappers[ $name ] = $mapper;
			}
		}
	}

	/**
	 * The converter with every shipped mapper.
	 */
	public static function withDefaults(): self {
		return new self(
			array(
				new Mappers\SectionHeadMapper(),
				new Mappers\ProseMapper(),
				new Mappers\PullQuoteMapper(),
			)
		);
	}

	/**
	 * Legacy block names that have a mapper, sorted.
	 *
	 * @return list<string>
	 */
	public function mappedNames(): array {
		$names = array_keys( $this->mappers );
		sort( $names );
		return $names;
	}

	/**
	 * Converts markup. Markup without a legacy block comes back unchanged,
	 * byte for byte.
	 *
	 * @param string $markup Serialized blocks.
	 * @param Media  $media  Image lookups.
	 */
	public function convert( string $markup, Media $media ): Result {
		$context = new Context( $this, $media );
		if ( ! str_contains( $markup, '<!-- wp:pediment/' ) ) {
			return $context->result( $markup );
		}
		// Registers theme style-variation names, as Policy::check() does, so
		// className rules see the same styles the Policy accepts.
		\WP_Theme_JSON_Resolver::get_theme_data();
		$blocks = $this->convertList( parse_blocks( $markup ), $context );
		return $context->result( $context->changed() ? serialize_blocks( $blocks ) : $markup );
	}

	/**
	 * Converts a list of parsed blocks; removed blocks are left out.
	 * Called through Context::inner().
	 *
	 * @param array   $blocks  Parsed blocks.
	 * @param Context $context Run.
	 * @return list<array>
	 */
	public function convertList( array $blocks, Context $context ): array {
		$out = array();
		foreach ( $blocks as $block ) {
			$converted = $this->convertBlock( $block, $context );
			if ( null !== $converted ) {
				$out[] = $converted;
			}
		}
		return $out;
	}

	/**
	 * One block: mapped when it has a mapper, else kept with its inner
	 * blocks walked.
	 *
	 * @param array   $block   Parsed block.
	 * @param Context $context Run.
	 */
	private function convertBlock( array $block, Context $context ): ?array {
		$name = $block['blockName'] ?? null;
		if ( is_string( $name ) && isset( $this->mappers[ $name ] ) ) {
			$context->markConverted( $name );
			$mapped = $this->mappers[ $name ]->map( $block, $context );
			if ( null === $mapped ) {
				$context->note( "{$name}: rendered nothing, removed" );
			}
			return $mapped;
		}
		if ( is_string( $name ) && in_array( $name, Policy::LEGACY, true ) ) {
			$context->markUnmapped( $name );
		}
		return $this->walk( $block, $context );
	}

	/**
	 * Converts a kept block's inner blocks and keeps innerContent aligned:
	 * every null chunk stands for one inner block, so a removed inner block
	 * takes its chunk with it.
	 *
	 * @param array   $block   Parsed block.
	 * @param Context $context Run.
	 */
	private function walk( array $block, Context $context ): array {
		if ( empty( $block['innerBlocks'] ) ) {
			return $block;
		}
		$inner   = array();
		$content = array();
		$next    = 0;
		foreach ( (array) $block['innerContent'] as $chunk ) {
			if ( null !== $chunk ) {
				$content[] = $chunk;
				continue;
			}
			$child = $this->convertBlock( $block['innerBlocks'][ $next++ ], $context );
			if ( null !== $child ) {
				$inner[]   = $child;
				$content[] = null;
			}
		}
		$block['innerBlocks']  = $inner;
		$block['innerContent'] = $content;
		return $block;
	}
}
```

```php
	/**
	 * Builds core/image. Reads id, align, sizeSlug, width, height, aspectRatio,
	 * scale, className and a style.border.radius token.
	 *
	 * @param array  $attrs   Attributes.
	 * @param string $url     Image URL (unescaped).
	 * @param string $alt     Alt text (unescaped).
	 * @param string $caption Escaped caption, '' for none.
	 */
	public static function image( array $attrs, string $url, string $alt, string $caption = '' ): array {
		$radius = (string) ( $attrs['style']['border']['radius'] ?? '' );
		$class  = self::classes(
			'wp-block-image',
			self::align( $attrs ),
			isset( $attrs['sizeSlug'] ) ? 'size-' . $attrs['sizeSlug'] : '',
			isset( $attrs['width'] ) || isset( $attrs['height'] ) ? 'is-resized' : '',
			'' !== $radius ? 'has-custom-border' : '',
			(string) ( $attrs['className'] ?? '' )
		);
		$styles = array();
		if ( '' !== $radius ) {
			$styles[] = 'border-radius:' . $radius;
		}
		foreach ( array( 'aspectRatio' => 'aspect-ratio', 'scale' => 'object-fit', 'width' => 'width', 'height' => 'height' ) as $key => $property ) {
			if ( isset( $attrs[ $key ] ) ) {
				$styles[] = $property . ':' . $attrs[ $key ];
			}
		}
		$style = array() === $styles ? '' : ' style="' . esc_attr( implode( ';', $styles ) ) . '"';
		$img   = sprintf( '<img src="%s" alt="%s" class="wp-image-%d"%s/>', esc_url( $url ), esc_attr( $alt ), (int) ( $attrs['id'] ?? 0 ), $style );
		$cap   = '' === $caption ? '' : '<figcaption class="wp-element-caption">' . $caption . '</figcaption>';
		return self::leaf( 'core/image', $attrs, "<figure class=\"{$class}\">{$img}{$cap}</figure>" );
	}
```

```php
/**
 * Grid (3 columns, 2 for exactly four cards, min 16rem) of group.is-style-card
 * → image (when set), h3, text, link paragraph. The icon has no core
 * equivalent and is dropped (noted).
 */
final class FeatureGridMapper implements Mapper {

	public function names(): array {
		return array( 'pediment/feature-grid', 'pediment/feature' );
	}

	public function map( array $block, Context $context ): ?array {
		return 'pediment/feature' === $block['blockName'] ? $this->feature( $block, $context ) : $this->grid( $block, $context );
	}

	/**
	 * The grid.
	 *
	 * @param array   $block   Legacy block.
	 * @param Context $context Run.
	 */
	private function grid( array $block, Context $context ): ?array {
		$cards = $context->inner( (array) ( $block['innerBlocks'] ?? array() ) );
		if ( array() === $cards ) {
			return null;
		}
		$group           = array( 'tagName' => 'section' );
		$group           = Attrs::put( $group, 'align', $context->align( $block ) );
		$group           = Attrs::put( $group, 'className', $context->className( $block, 'core/group' ) );
		$group['layout'] = array(
			'type'               => 'grid',
			'columnCount'        => 4 === count( $cards ) ? 2 : 3,
			'minimumColumnWidth' => '16rem',
		);
		return Build::group( $group + $context->carry( $block, 'Features' ), $cards );
	}

	/**
	 * One card.
	 *
	 * @param array   $block   Legacy block.
	 * @param Context $context Run.
	 */
	private function feature( array $block, Context $context ): ?array {
		$attrs = (array) ( $block['attrs'] ?? array() );
		$title = Attrs::rich( $attrs, 'title' );
		$text  = Attrs::rich( $attrs, 'text' );
		if ( '' === $title && '' === $text ) {
			return null;
		}

		$inner = array();
		$id    = Attrs::int( $attrs, 'imageId' );
		$url   = $id > 0 ? $context->media()->url( $id, 'medium' ) : '';
		if ( '' !== $url ) {
			$inner[] = Build::image(
				array(
					'id'              => $id,
					'width'           => '88px',
					'height'          => '88px',
					'aspectRatio'     => '1',
					'scale'           => 'cover',
					'sizeSlug'        => 'medium',
					'linkDestination' => 'none',
					'align'           => 'center',
					'style'           => array( 'border' => array( 'radius' => 'var(--wp--custom--radius--md)' ) ),
				),
				$url,
				$context->media()->alt( $id )
			);
		} else {
			if ( $id > 0 ) {
				$context->note( "pediment/feature: image {$id} not found, left out" );
			}
			$context->note( 'pediment/feature: icon dropped, core blocks cannot show the icon set' );
		}
		if ( '' !== $title ) {
			$inner[] = Build::heading( 3, $title, array( 'textAlign' => 'center' ) );
		}
		if ( '' !== $text ) {
			$inner[] = Build::paragraph( $text, array( 'align' => 'center' ) );
		}
		$link_text = Attrs::rich( $attrs, 'linkText' );
		$link_url  = Attrs::url( $attrs, 'linkUrl' );
		if ( '' !== $link_text && '' !== $link_url ) {
			$inner[] = Build::paragraph( "<a href=\"{$link_url}\">{$link_text}</a>", array( 'align' => 'center' ) );
		}

		$group = array(
			'className' => $context->className( $block, 'core/group', 'is-style-card' ),
			'layout'    => array( 'type' => 'constrained' ),
		);
		return Build::group( $group + $context->carry( $block, 'Feature' ), $inner );
	}
}
```

```php
<?php
/**
 * Mapper: pediment/faq + pediment/faq-item → stack of core/details accordions.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert\Mappers;

use Pediment\Convert\Attrs;
use Pediment\Convert\Build;
use Pediment\Convert\Context;
use Pediment\Convert\Mapper;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * Vertical flex group → details.is-style-accordion (summary = question,
 * one paragraph = answer). A lone faq-item becomes a lone details block.
 */
final class FaqMapper implements Mapper {

	public function names(): array {
		return array( 'pediment/faq', 'pediment/faq-item' );
	}

	public function map( array $block, Context $context ): ?array {
		if ( 'pediment/faq-item' === $block['blockName'] ) {
			return $this->item( $block, $context );
		}
		$items = $context->inner( (array) ( $block['innerBlocks'] ?? array() ) );
		if ( array() === $items ) {
			return null;
		}
		$group           = array( 'tagName' => 'section' );
		$group           = Attrs::put( $group, 'align', $context->align( $block ) );
		$group           = Attrs::put( $group, 'className', $context->className( $block, 'core/group' ) );
		$group['layout'] = array(
			'type'           => 'flex',
			'orientation'    => 'vertical',
			'justifyContent' => 'stretch',
		);
		return Build::group( $group + $context->carry( $block, 'FAQ' ), $items );
	}

	/**
	 * One question.
	 *
```

```php
/**
 * Grid (2 columns, min 20rem) of group.is-style-quote-card → core/quote.
 * Without an avatar the byline is the quote's citation; with one, a flex
 * "Byline" group holds the rounded avatar and the byline paragraph.

final class TestimonialGridMapper implements Mapper {

	public function names(): array {
		return array( 'pediment/testimonial-grid', 'pediment/testimonial' );
	}

	public function map( array $block, Context $context ): ?array {
		if ( 'pediment/testimonial' === $block['blockName'] ) {

		}
		$cards = $context->inner( (array) ( $block['innerBlocks'] ?? array() ) );
		if ( array() === $cards ) {
			return null;
		}
		$group           = array( 'tagName' => 'section' );
		$group           = Attrs::put( $group, 'align', $context->align( $block ) );
		$group           = Attrs::put( $group, 'className', $context->className( $block, 'core/group' ) );

			'columnCount'        => 2,

	/**
	 * One testimonial.
	 *
	 * @param array   $block   Legacy block.
	 * @param Context $context Run.
	 */
	private function testimonial( array $block, Context $context ): ?array {
		$attrs = (array) ( $block['attrs'] ?? array() );
		$quote = Attrs::rich( $attrs, 'quote' );
		if ( '' === $quote ) {
			return null;
		}
		$name   = Attrs::rich( $attrs, 'authorName' );
		$role   = Attrs::rich( $attrs, 'authorRole' );
		$byline = implode( '<br>', array_filter( array( '' === $name ? '' : "<strong>{$name}</strong>", $role ), static fn( string $part ): bool => '' !== $part ) );
		$id     = Attrs::int( $attrs, 'avatarId' );
		$url    = $id > 0 ? $context->media()->url( $id, 'thumbnail' ) : '';
		if ( $id > 0 && '' === $url ) {
			$context->note( "pediment/testimonial: avatar {$id} not found, left out" );
		}

		$inner = array( Build::quote( array(), array( Build::paragraph( $quote ) ), '' === $url ? $byline : '' ) );
		if ( '' !== $url ) {
			$person = array(
				Build::image(
					array(
						'id'              => $id,
						'width'           => '40px',
						'height'          => '40px',
						'aspectRatio'     => '1',
						'scale'           => 'cover',
						'sizeSlug'        => 'thumbnail',
						'linkDestination' => 'none',
						'className'       => 'is-style-rounded',
					),
					$url,
					$context->media()->alt( $id )
				),
			);
			if ( '' !== $byline ) {
				$person[] = Build::paragraph( $byline );
			}
			$inner[] = Build::group(
				array(
					'layout'   => array(
						'type'     => 'flex',
						'flexWrap' => 'nowrap',
					),
					'metadata' => array( 'name' => 'Byline' ),
				),
				$person
			);
		}

		$group = array(
			'className' => $context->className( $block, 'core/group', 'is-style-quote-card' ),
			'layout'    => array( 'type' => 'constrained' ),
		);
		return Build::group( $group + $context->carry( $block, 'Testimonial' ), $inner );
	}
```

```php
<?php
/**
 * Mapper: pediment/hero → group, cover or columns, by variant.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert\Mappers;

use Pediment\Convert\Attrs;
use Pediment\Convert\Build;
use Pediment\Convert\Context;
use Pediment\Convert\Mapper;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * Variants: default / centered → section group (h1, lead, pill button);
 * media-bg → cover.is-style-media-card with the image and a primary overlay;
 * stat-card → two columns: copy, buttons and ticks; a media-card cover with
 * a card holding the stat and metrics.
 */
final class HeroMapper implements Mapper {

	private const VARIANTS = array( 'default', 'centered', 'media-bg', 'stat-card' );

	public function names(): array {
		return array( 'pediment/hero' );
	}

	public function map( array $block, Context $context ): ?array {
		$attrs   = (array) ( $block['attrs'] ?? array() );
		$variant = Attrs::string( $attrs, 'variant', 'default' );
		$allowed = function_exists( 'pediment_hero_variants' ) ? (array) pediment_hero_variants() : self::VARIANTS;
		if ( ! in_array( $variant, $allowed, true ) ) {
			$variant = 'default';
		}
		if ( ! in_array( $variant, self::VARIANTS, true ) ) {
			$context->note( "pediment/hero: variant {$variant} has no mapping, converted as default" );
			$variant = 'default';
		}
		if ( 'media-bg' === $variant ) {
			return $this->mediaBackground( $block, $context );
		}
		if ( 'stat-card' === $variant ) {
			return $this->statCard( $block, $context );
		}
		$inner = $this->copy( $attrs, 'centered' === $variant );
		if ( array() === $inner ) {
			return null;
		}
		$group           = array( 'tagName' => 'section' );
		$group           = Attrs::put( $group, 'align', $context->align( $block ) );
		$group           = Attrs::put( $group, 'className', $context->className( $block, 'core/group' ) );
		$group['layout'] = array( 'type' => 'constrained' );
		return Build::group( $group + $context->carry( $block, 'Hero' ), $inner );
	}

	/**
	 * Headline, subheadline and the primary button — the parts that are set.
	 *
	 * @param array $attrs  Legacy attributes.
	 * @param bool  $center Centre the text and the button.
	 * @return list<array>
	 */
	private function copy( array $attrs, bool $center ): array {
		$inner    = array();
		$headline = Attrs::rich( $attrs, 'headline' );
		if ( '' !== $headline ) {
			$inner[] = Build::heading( 1, $headline, $center ? array( 'textAlign' => 'center' ) : array() );
		}
		$sub = Attrs::rich( $attrs, 'subheadline' );
		if ( '' !== $sub ) {
			$inner[] = Build::paragraph( $sub, ( $center ? array( 'align' => 'center' ) : array() ) + array( 'className' => 'is-style-lead' ) );
		}
		$button = $this->button( $attrs, 'ctaText', 'ctaUrl', 'pill' );
		if ( null !== $button ) {
			$layout  = $center ? array(
				'layout' => array(
					'type'           => 'flex',
					'justifyContent' => 'center',
				),
			) : array();
			$inner[] = Build::buttons( array( $button ), $layout );
		}
		return $inner;
	}

	/**
	 * A button when both its text and URL are set (as render.php required).
	 *
	 * @param array  $attrs Legacy attributes.
	 * @param string $text  Text attribute key.
	 * @param string $url   URL attribute key.
	 * @param string $style Style slug.
	 */
	private function button( array $attrs, string $text, string $url, string $style ): ?array {
		$label = Attrs::rich( $attrs, $text );
		$href  = Attrs::url( $attrs, $url );
		return '' === $label || '' === $href ? null : Build::button( $label, $href, $style );
	}

	/**
	 * The media-bg variant.
	 *
	 * @param array   $block   Legacy block.
	 * @param Context $context Run.
	 */
	private function mediaBackground( array $block, Context $context ): ?array {
		$attrs = (array) ( $block['attrs'] ?? array() );
		$inner = $this->copy( $attrs, false );
		$id    = Attrs::int( $attrs, 'mediaId' );
		$url   = $id > 0 ? $context->media()->url( $id, 'full' ) : '';
		if ( $id > 0 && '' === $url ) {
			$context->note( "pediment/hero: image {$id} not found, left out" );
		}
		if ( '' === $url && array() === $inner ) {
			return null;
		}
		$cover = array();
		if ( '' !== $url ) {
			$cover = array(
				'url'      => $url,
				'id'       => $id,
				'dimRatio' => 60,
			);
		}
		$cover['overlayColor']       = 'primary';
		$cover['isUserOverlayColor'] = true;
		$cover['tagName']            = 'section';
		$cover                       = Attrs::put( $cover, 'align', $context->align( $block ) );
		$cover['className']          = $context->className( $block, 'core/cover', 'is-style-media-card' );
		$cover['layout']             = array( 'type' => 'constrained' );
		return Build::cover( $cover + $context->carry( $block, 'Hero' ), $inner );
	}

	/**
	 * The stat-card variant.
	 *
	 * @param array   $block   Legacy block.
	 * @param Context $context Run.
	 */
	private function statCard( array $block, Context $context ): array {
		$attrs   = (array) ( $block['attrs'] ?? array() );
		$left    = array();
		$eyebrow = Attrs::rich( $attrs, 'eyebrow' );
		if ( '' !== $eyebrow ) {
			$left[] = Build::paragraph( $eyebrow, array( 'className' => 'is-style-eyebrow' ) );
		}
		$headline = Attrs::rich( $attrs, 'headline' );
		if ( '' !== $headline ) {
			$left[] = Build::heading( 1, $headline );
		}
		$sub = Attrs::rich( $attrs, 'subheadline' );
		if ( '' !== $sub ) {
			$left[] = Build::paragraph( $sub, array( 'className' => 'is-style-lead' ) );
		}
		$buttons = array_values( array_filter( array( $this->button( $attrs, 'ctaText', 'ctaUrl', 'pill' ), $this->button( $attrs, 'secondaryText', 'secondaryUrl', 'pill-ghost' ) ) ) );
		if ( array() !== $buttons ) {
			$left[] = Build::buttons( $buttons );
		}
		$ticks = array();
		foreach ( is_array( $attrs['ticks'] ?? null ) ? $attrs['ticks'] : array() as $tick ) {
			$tick = is_scalar( $tick ) ? Attrs::html( (string) $tick ) : '';
			if ( '' !== $tick ) {
				$ticks[] = $tick;
			}
		}
		if ( array() !== $ticks ) {
			$left[] = Build::bulletList( $ticks );
		}

		$columns = Attrs::put( array(), 'align', $context->align( $block ) );
		$columns = Attrs::put( $columns, 'className', $context->className( $block, 'core/columns' ) );
		return Build::columns(
			$columns + $context->carry( $block, 'Hero' ),
			array( Build::column( '52%', $left ), Build::column( '48%', array( $this->figure( $attrs, $context ) ) ) )
		);
	}

	/**
	 * The stat-card's image with the stat card on it.
	 *
	 * @param array   $attrs   Legacy attributes.
	 * @param Context $context Run.
	 */
	private function figure( array $attrs, Context $context ): array {
		$value   = Attrs::rich( $attrs, 'statValue' );
		$text    = Attrs::rich( $attrs, 'statText' );
		$metrics = array();
		foreach ( is_array( $attrs['metrics'] ?? null ) ? $attrs['metrics'] : array() as $metric ) {
			$metric = is_array( $metric ) ? $metric : array();
			$parts  = array_filter(
				array(
					'' === Attrs::rich( $metric, 'value' ) ? '' : '<strong>' . Attrs::rich( $metric, 'value' ) . '</strong>',
					Attrs::rich( $metric, 'label' ),
				),
				static fn( string $part ): bool => '' !== $part
			);
			if ( array() !== $parts ) {
				$metrics[] = Build::paragraph( implode( '<br>', $parts ) );
			}
		}

		$card = array();
		if ( '' !== $value || '' !== $text || array() !== $metrics ) {
			$stat = array(
				Build::group(
					array(
						'className' => 'is-style-stat',
						'layout'    => array( 'type' => 'constrained' ),
						'metadata'  => array( 'name' => 'Stat' ),
					),
					array( Build::paragraph( $value ), Build::paragraph( $text ) )
				),
			);
			if ( array() !== $metrics ) {
				$stat[] = Build::group(
					array(
						'layout'   => array(
							'type'           => 'flex',
							'flexWrap'       => 'wrap',
							'justifyContent' => 'center',
						),
						'metadata' => array( 'name' => 'Metrics' ),
					),
					$metrics
				);
			}
			$card[] = Build::group(
				array(
					'className' => 'is-style-card',
					'layout'    => array( 'type' => 'constrained' ),
					'metadata'  => array( 'name' => 'Hero stat' ),
				),
				$stat
			);
		}

		$id    = Attrs::int( $attrs, 'mediaId' );
		$url   = $id > 0 ? $context->media()->url( $id, 'large' ) : '';
		$cover = array();
		if ( '' !== $url ) {
			$cover             = array(
				'url' => $url,
				'id'  => $id,
			);
			$cover             = Attrs::put( $cover, 'alt', $context->media()->alt( $id ) );
			$cover['dimRatio'] = 0;
		} else {
			if ( $id > 0 ) {
				$context->note( "pediment/hero: image {$id} not found, left out" );
			}
			$cover['overlayColor'] = 'primary';
		}
		$cover['isUserOverlayColor'] = true;
		$cover['contentPosition']    = 'bottom center';
		// Dark text: the stat card is light, on the image and on the primary fill.
		$cover['isDark']    = false;
		$cover['className'] = 'is-style-media-card';
		$cover['style']     = array( 'dimensions' => array( 'aspectRatio' => '5/6' ) );
		$cover['layout']    = array( 'type' => 'constrained' );
		$cover['metadata']  = array( 'name' => 'Hero media' );
		return Build::cover( $cover, $card );
	}
}
```

```php
	public function names(): array {
		return array( 'pediment/media-text' );

		$attrs = (array) ( $block['attrs'] ?? array() );
		$inner = $context->inner( (array) ( $block['innerBlocks'] ?? array() ) );
```

```php
<?php
/**
 * Line diff for dry-run previews.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * A unified-style line diff: "@@" hunks, " " context, "-" removed, "+" added.
 */
final class Diff {

	/**
	 * Longest diff returned, in bytes; longer diffs end with a marker line.
	 */
	public const MAX_BYTES = 20000;

	/**
	 * Unchanged lines shown around each change.
	 */
	private const CONTEXT = 2;

	/**
	 * Largest middle section compared line by line; above it the whole
	 * middle shows as removed and added.
	 */
	private const MAX_CELLS = 250000;

	/**
	 * The diff of two texts; '' when they are equal.
	 *
	 * @param string $before Old text.
	 * @param string $after  New text.
	 */
	public static function unified( string $before, string $after ): string {
		if ( $before === $after ) {
			return '';
		}
		$old    = explode( "\n", $before );
		$new    = explode( "\n", $after );
		$n      = count( $old );
		$m      = count( $new );
		$prefix = 0;
		while ( $prefix < $n && $prefix < $m && $old[ $prefix ] === $new[ $prefix ] ) {
			++$prefix;
		}
		$suffix = 0;
		while ( $suffix < $n - $prefix && $suffix < $m - $prefix && $old[ $n - 1 - $suffix ] === $new[ $m - 1 - $suffix ] ) {
			++$suffix;
		}
		$ops = array();
		for ( $i = 0; $i < $prefix; $i++ ) {
			$ops[] = array( ' ', $old[ $i ] );
		}
		array_push( $ops, ...self::middle( array_slice( $old, $prefix, $n - $prefix - $suffix ), array_slice( $new, $prefix, $m - $prefix - $suffix ) ) );
		for ( $i = $n - $suffix; $i < $n; $i++ ) {
			$ops[] = array( ' ', $old[ $i ] );
		}
		return self::hunks( $ops );
	}

	/**
	 * Edit operations for the changed middle (longest common subsequence).
	 *
	 * @param list<string> $left  Old lines.
	 * @param list<string> $right New lines.
	 * @return list<array{0:string,1:string}>
	 */
	private static function middle( array $left, array $right ): array {
		$n = count( $left );
		$m = count( $right );
		if ( $n * $m > self::MAX_CELLS ) {
			return array_merge(
				array_map( static fn( string $line ): array => array( '-', $line ), $left ),
				array_map( static fn( string $line ): array => array( '+', $line ), $right )
			);
		}
		$lcs = array_fill( 0, $n + 1, array_fill( 0, $m + 1, 0 ) );
		for ( $i = $n - 1; $i >= 0; $i-- ) {
			for ( $j = $m - 1; $j >= 0; $j-- ) {
				$lcs[ $i ][ $j ] = $left[ $i ] === $right[ $j ] ? $lcs[ $i + 1 ][ $j + 1 ] + 1 : max( $lcs[ $i + 1 ][ $j ], $lcs[ $i ][ $j + 1 ] );
			}
		}
		$ops = array();
		$i   = 0;
		$j   = 0;
		while ( $i < $n || $j < $m ) {
			if ( $i < $n && $j < $m && $left[ $i ] === $right[ $j ] ) {
				$ops[] = array( ' ', $left[ $i++ ] );
				++$j;
			} elseif ( $i < $n && ( $j >= $m || $lcs[ $i + 1 ][ $j ] >= $lcs[ $i ][ $j + 1 ] ) ) {
				$ops[] = array( '-', $left[ $i++ ] );
			} else {
				$ops[] = array( '+', $right[ $j++ ] );
			}
		}
		return $ops;
	}

	/**
	 * Groups operations into hunks with context and caps the length.
	 *
	 * @param list<array{0:string,1:string}> $ops Operations.
	 */
	private static function hunks( array $ops ): string {
		$show = array();
		$last = count( $ops ) - 1;
		foreach ( $ops as $k => $op ) {
			if ( ' ' !== $op[0] ) {
				$to = min( $last, $k + self::CONTEXT );
				for ( $c = max( 0, $k - self::CONTEXT ); $c <= $to; $c++ ) {
					$show[ $c ] = true;
				}
			}
		}
		$out      = '';
		$previous = -2;
		$old_line = 1;
		$new_line = 1;
		foreach ( $ops as $k => $op ) {
			if ( isset( $show[ $k ] ) ) {
				if ( $k !== $previous + 1 ) {
					$out .= "@@ -{$old_line} +{$new_line} @@\n";
				}
				$out     .= $op[0] . $op[1] . "\n";
				$previous = $k;
			}
			$old_line += '+' === $op[0] ? 0 : 1;
			$new_line += '-' === $op[0] ? 0 : 1;
		}
		if ( strlen( $out ) > self::MAX_BYTES ) {
			$out = mb_strcut( $out, 0, self::MAX_BYTES, 'UTF-8' ) . "\n… diff truncated at " . self::MAX_BYTES . " bytes\n";
		}
		return $out;
	}
}
```

```php
<?php
/**
 * Converts stored posts: pages, posts, synced patterns and DB templates.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert;

use Pediment\Abilities\PageData;
use Pediment\Content\InvalidBlockLog;
use Pediment\Content\Policy;
use Pediment\Language\LanguageRegistry;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * The one service behind the ability, the wp-admin screen and WP-CLI.
 */
final class PostConverter {

	/**
	 * Post types that can hold legacy blocks and render them on pages.
	 */
	public const TYPES = array( 'page', 'post', 'wp_block', 'wp_template', 'wp_template_part' );

	/**
	 * Template types; editing them also needs edit_theme_options.
	 */
	public const TEMPLATE_TYPES = array( 'wp_template', 'wp_template_part' );

	private const STATUSES = array( 'publish', 'draft', 'pending', 'private', 'future' );

	/**
	 * Strips the block path from a Policy message ("blocks[0] core/group > [1] core/paragraph: …").
	 */
	private const PATH = '/^blocks\[\d+\](?: \S+)?(?: > \[\d+\](?: \S+)?)*: /';

	/**
	 * Constructor.
	 *
	 * @param Converter $converter Converter.
	 * @param Policy    $policy    Content rules.
	 * @param Media     $media     Image lookups.
	 */
	public function __construct( private Converter $converter, private Policy $policy, private Media $media ) {}

	/**
	 * The service with the shipped mappers and the media library.
	 */
	public static function create(): self {
		return new self( Converter::withDefaults(), new Policy(), new AttachmentMedia() );
	}

	/**
	 * IDs of every convertible post that holds a legacy block, in every
	 * language, ascending.
	 *
	 * @return list<int>
	 */
	public function candidates(): array {
		$ids = get_posts(
			LanguageRegistry::provider()->unscopedQuery(
				array(
					'post_type'      => self::TYPES,
					'post_status'    => self::STATUSES,
					'posts_per_page' => -1,
					'fields'         => 'ids',
					'orderby'        => 'ID',
					'order'          => 'ASC',
					'no_found_rows'  => true,
				)
			)
		);
		$out = array();
		foreach ( array_map( 'intval', $ids ) as $id ) {
			$content = (string) get_post_field( 'post_content', $id, 'raw' );
			if ( str_contains( $content, '<!-- wp:pediment/' ) && array() !== $this->policy->legacyBlocksIn( $content ) ) {
				$out[] = $id;
			}
		}
		return $out;
	}

	/**
	 * Converts (or previews) several posts.
	 *
	 * @param list<int>          $ids     Post IDs.
	 * @param bool               $dry_run Preview only; nothing is written.
	 * @param callable|null      $can     fn(int $id): bool — posts it refuses are skipped. Null skips no post (WP-CLI).
	 * @return array{dryRun:bool,posts:list<array>,summary:array<string,int>}
	 */
	public function runMany( array $ids, bool $dry_run, ?callable $can = null ): array {
		$posts = array();
		foreach ( array_values( array_unique( array_map( 'intval', $ids ) ) ) as $id ) {
			$posts[] = null !== $can && get_post( $id ) instanceof \WP_Post && ! $can( $id )
				? $this->skipped( $id, 'you cannot edit this post' )
				: $this->run( $id, $dry_run );
		}
		return array(
			'dryRun'  => $dry_run,
			'posts'   => $posts,
			'summary' => self::summary( $posts ),
		);
	}

	/**
	 * Converts (or previews) one post.
	 *
	 * Status: preview (dry run, would convert), converted, unchanged (nothing
	 * to convert), failed (conversion would add content-rule errors, or the
	 * save failed; nothing written), skipped (not a convertible post).
	 *
	 * @param int  $id      Post ID.
	 * @param bool $dry_run Preview only.
	 * @return array{id:int,type:string,title:string,language:string,status:string,converted:list<string>,blocks:int,unmapped:list<string>,notes:list<string>,errors:list<string>,existingErrors:list<string>,diff:string,revision:int,restoreRevision:int}
	 */
	public function run( int $id, bool $dry_run ): array {
		$post = get_post( $id );
		if ( ! $post instanceof \WP_Post ) {
			return $this->skipped( $id, 'no post with this id' );
		}
		if ( ! in_array( $post->post_type, self::TYPES, true ) ) {
			return $this->skipped( $id, "post type {$post->post_type} is not converted" );
		}

		$before = $post->post_content;
		$result = $this->converter->convert( $before, $this->media );
		$report = $this->report( $post, $result );
		if ( ! $result->changed() ) {
			return $report;
		}

		$old_errors               = $this->policy->check( $before )['errors'];
		$new_errors               = $this->policy->check( $result->markup )['errors'];
		$report['existingErrors'] = $old_errors;
		$report['errors']         = self::addedErrors( $old_errors, $new_errors );
		if ( array() !== $report['errors'] ) {
			$report['status'] = 'failed';
			return $report;
		}
		if ( $dry_run ) {
			$report['status'] = 'preview';
			$report['diff']   = Diff::unified( $before, $result->markup );
			return $report;
		}

		// Seeded or hand-created posts may have no revision of their current
		// content; save one so rollback-page can restore the legacy version.
		$saved   = wp_save_post_revision( $id );
		$restore = is_int( $saved ) && $saved > 0 ? $saved : PageData::latestRevision( $id );
		$updated = wp_update_post(
			wp_slash(
				array(
					'ID'           => $id,
					'post_content' => $result->markup,
				)
			),
			true
		);
		if ( is_wp_error( $updated ) ) {
			$report['status'] = 'failed';
			$report['errors'] = array( $updated->get_error_message() );
			return $report;
		}
		InvalidBlockLog::clear( $id );
		$report['status']          = 'converted';
		$report['revision']        = PageData::latestRevision( $id );
		$report['restoreRevision'] = $restore;
		return $report;
	}

	/**
	 * Counts per status, plus the number of legacy blocks converted.
	 *
	 * @param list<array> $posts Post reports.
	 * @return array{posts:int,blocks:int,converted:int,preview:int,unchanged:int,failed:int,skipped:int}
	 */
	public static function summary( array $posts ): array {
		$summary = array(
			'posts'     => count( $posts ),
			'blocks'    => 0,
			'converted' => 0,
			'preview'   => 0,
			'unchanged' => 0,
			'failed'    => 0,
			'skipped'   => 0,
		);
		foreach ( $posts as $post ) {
			++$summary[ $post['status'] ];
			$summary['blocks'] += in_array( $post['status'], array( 'converted', 'preview' ), true ) ? $post['blocks'] : 0;
		}
		return $summary;
	}

	/**
	 * Errors in $after whose message (without its block path) is not in $before.
	 * Block paths shift when a converted block is removed, so messages are
	 * compared without them.
	 *
	 * @param list<string> $before Errors before conversion.
	 * @param list<string> $after  Errors after conversion.
	 * @return list<string>
	 */
	public static function addedErrors( array $before, array $after ): array {
		$strip = static fn( string $message ): string => (string) preg_replace( self::PATH, '', $message );
		$known = array_map( $strip, $before );
		return array_values( array_filter( $after, static fn( string $message ): bool => ! in_array( $strip( $message ), $known, true ) ) );
	}

	/**
	 * The report of a post the converter looked at.
	 *
	 * @param \WP_Post $post   Post.
	 * @param Result   $result Conversion result.
	 */
	private function report( \WP_Post $post, Result $result ): array {
		$names = array_values( array_unique( $result->converted ) );
		sort( $names );
		return array(
			'id'              => $post->ID,
			'type'            => $post->post_type,
			'title'           => $post->post_title,
			'language'        => LanguageRegistry::provider()->languageOf( $post->ID ),
			'status'          => 'unchanged',
			'converted'       => $names,
			'blocks'          => count( $result->converted ),
			'unmapped'        => $result->unmapped,
			'notes'           => $result->notes,
			'errors'          => array(),
			'existingErrors'  => array(),
			'diff'            => '',
			'revision'        => 0,
			'restoreRevision' => 0,
		);
	}

	/**
	 * The report of a post the converter did not look at.
	 *
	 * @param int    $id     Post ID.
	 * @param string $reason Why.
	 */
	private function skipped( int $id, string $reason ): array {
		$post = get_post( $id );
		return array(
			'id'              => $id,
			'type'            => $post instanceof \WP_Post ? $post->post_type : '',
			'title'           => $post instanceof \WP_Post ? $post->post_title : '',
			'language'        => '',
			'status'          => 'skipped',
			'converted'       => array(),
			'blocks'          => 0,
			'unmapped'        => array(),
			'notes'           => array( $reason ),
			'errors'          => array(),
			'existingErrors'  => array(),
			'diff'            => '',
			'revision'        => 0,
			'restoreRevision' => 0,
		);
	}
}
```

```php
			'type'  => 'array',

				'posts'   => array(
					'type'  => 'array',
					'items' => array(
						'type'       => 'object',
						'properties' => array(
							'id'              => array( 'type' => 'integer' ),
							'type'            => array( 'type' => 'string' ),
							'title'           => array( 'type' => 'string' ),
							'language'        => array( 'type' => 'string' ),
							'status'          => array(
								'type' => 'string',
								'enum' => array( 'preview', 'converted', 'unchanged', 'failed', 'skipped' ),
							),
							'converted'       => $list,
							'blocks'          => array( 'type' => 'integer' ),
							'unmapped'        => $list,
							'notes'           => $list,
							'errors'          => $list,
							'existingErrors'  => $list,
							'diff'            => array( 'type' => 'string' ),
							'revision'        => array( 'type' => 'integer' ),
							'restoreRevision' => array( 'type' => 'integer' ),
						),
						'required'   => array( 'id', 'type', 'title', 'language', 'status', 'converted', 'blocks', 'unmapped', 'notes', 'errors', 'existingErrors', 'diff', 'revision', 'restoreRevision' ),
					),
				),
				'summary' => array(
					'type'       => 'object',
					'properties' => array_fill_keys( array( 'posts', 'blocks', 'converted', 'preview', 'unchanged', 'failed', 'skipped' ), array( 'type' => 'integer' ) ),
				),
			),
			'required'   => array( 'dryRun', 'posts', 'summary' ),
		);
	}

	protected function annotations(): array {
		return array(
			'readonly'    => false,
			'destructive' => true,
			'idempotent'  => true,
		);
	}

	public function permission( $input ): bool {
		if ( ! current_user_can( 'edit_pages' ) ) {
			return false;
		}
		foreach ( (array) ( ( (array) $input )['ids'] ?? array() ) as $id ) {
			$post = get_post( (int) $id );
			if ( ! $post instanceof \WP_Post ) {
				continue;
			}
			if ( ! current_user_can( 'edit_post', $post->ID ) ) {
				return false;
			}
			if ( in_array( $post->post_type, PostConverter::TEMPLATE_TYPES, true ) && ! current_user_can( 'edit_theme_options' ) ) {
				return false;
			}
		}
		return true;
	}

	public function execute( $input ) {
		$input   = (array) $input;
		// The REST route passes DELETE query values as strings ("false").
		$all     = rest_sanitize_boolean( $input['all'] ?? false );
		$dry_run = rest_sanitize_boolean( $input['dry_run'] ?? true );
		$ids     = array_map( 'intval', (array) ( $input['ids'] ?? array() ) );
		if ( $all === ( array() !== $ids ) ) {
			return self::errorList( 'pediment_convert_scope', __( 'Say which posts to convert.', 'pediment' ), array( 'pass either ids (a list of post ids) or all: true, not both and not neither' ) );
		}
		$can = static function ( int $id ): bool {
			$post = get_post( $id );
			return $post instanceof \WP_Post
				&& current_user_can( 'edit_post', $id )
				&& ( ! in_array( $post->post_type, PostConverter::TEMPLATE_TYPES, true ) || current_user_can( 'edit_theme_options' ) );
		};
		return $this->converter->runMany( $all ? $this->converter->candidates() : $ids, $dry_run, $can );
	}
}
```

```markdown
## The Abilities REST route picks the HTTP method from the annotations

**Symptom.** `POST …/wp-abilities/v1/abilities/<name>/run` answers 405 ("Abilities
that perform destructive actions require DELETE method.") for an ability that works
through MCP and through `wp_get_ability( $name )->execute()`.
**Cause.** `WP_REST_Abilities_V1_Run_Controller` derives the method from the
ability's annotations: `readonly` → GET, `destructive` and `idempotent` → DELETE,
everything else → POST. GET and DELETE read the input from the `input` query
parameter, so every value arrives as a string (`"false"`, `"12"`). The input schema
check accepts those strings for `boolean` and `integer`, so the ability's `execute()`
receives them unchanged.
**Fix.** Call `pediment/convert-legacy` (destructive, idempotent) as
`DELETE …/pediment/convert-legacy/run&input[ids][0]=12&input[dry_run]=false`, and read
booleans in `execute()` with `rest_sanitize_boolean()`. A check such as
`false !== $input['dry_run']` treats the string `"false"` as true and silently turns
a real run into a dry run.
**Catch it early.** `ConvertLegacyTest::test_string_booleans_from_the_rest_route_are_read_as_booleans`
and `plugin/tests/e2e/convert-legacy.spec.ts`.
```

```php
<?php
/**
 * "Convert" tab in Settings → Pediment Theme: preview, then convert legacy blocks.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * The production route: hosts without WP-CLI convert here. The tab shows a
 * dry run of every post that holds a legacy block; one confirmed form post
 * converts the previewed posts.
 */
final class AdminTab {

	public const ACTION = 'pediment_convert_legacy';

	private const REPORT = 'pediment_convert_report_';

	/**
	 * Registers the tab and the form handler.
	 */
	public static function register(): void {
		add_action(
			'admin_menu',
			static function () {
				pediment_settings_register_tab( 'convert', __( 'Convert legacy blocks', 'pediment' ), array( self::class, 'render' ), 50 );
			}
		);
		add_action( 'admin_post_' . self::ACTION, array( self::class, 'handle' ) );
	}

	/**
	 * Who may convert here: the settings page needs manage_options, and the
	 * run touches templates, which need edit_theme_options.
	 */
	public static function allowed(): bool {
		return current_user_can( 'manage_options' ) && current_user_can( 'edit_theme_options' );
	}

	/**
	 * Renders the tab body: the last run's result (once), then the preview.
	 */
	public static function render(): void {
		if ( ! self::allowed() ) {
			echo '<p>' . esc_html__( 'You are not allowed to convert legacy blocks.', 'pediment' ) . '</p>';
			return;
		}
		$user = get_current_user_id();
		$last = get_transient( self::REPORT . $user );
		if ( is_array( $last ) ) {
			delete_transient( self::REPORT . $user );
			echo '<h2>' . esc_html__( 'Result', 'pediment' ) . '</h2>';
			self::table( $last );
		}

		$service = PostConverter::create();
		$preview = $service->runMany( $service->candidates(), true );
		$ready   = array_values( array_filter( $preview['posts'], static fn( array $post ): bool => 'preview' === $post['status'] ) );
		echo '<h2>' . esc_html__( 'Preview', 'pediment' ) . '</h2>';
		echo '<p>' . esc_html__( 'Posts, pages, synced patterns and templates in every language that still use legacy Pediment blocks. Nothing changes until you press the button. Every converted post keeps a revision of its old content.', 'pediment' ) . '</p>';
		if ( array() === $preview['posts'] ) {
			echo '<p><strong>' . esc_html__( 'No legacy blocks found. Nothing to convert.', 'pediment' ) . '</strong></p>';
			return;
		}
		self::table( $preview );
		?>
		<form method="post" action="<?php echo esc_url( admin_url( 'admin-post.php' ) ); ?>">
			<input type="hidden" name="action" value="<?php echo esc_attr( self::ACTION ); ?>" />
			<?php foreach ( $ready as $post ) : ?>
				<input type="hidden" name="ids[]" value="<?php echo esc_attr( (string) $post['id'] ); ?>" />
			<?php endforeach; ?>
			<?php wp_nonce_field( self::ACTION ); ?>
			<?php
			/* translators: %d: number of posts */
			submit_button( sprintf( _n( 'Convert %d post', 'Convert %d posts', count( $ready ), 'pediment' ), count( $ready ) ), 'primary', 'submit', true, array() === $ready ? array( 'disabled' => 'disabled' ) : array() );
			?>
		</form>
		<?php
	}

	/**
	 * Form handler: checks rights and nonce, converts, shows the result.
	 */
	public static function handle(): void {
		if ( ! self::allowed() ) {
			wp_die( esc_html__( 'You are not allowed to convert legacy blocks.', 'pediment' ), 403 );
		}
		check_admin_referer( self::ACTION );
		$ids = array_map( 'absint', (array) wp_unslash( $_POST['ids'] ?? array() ) ); // phpcs:ignore WordPress.Security.ValidatedSanitizedInput.InputNotSanitized -- absint on every item.
		self::process( array_values( array_filter( $ids ) ) );
		wp_safe_redirect( pediment_settings_page_url( 'convert' ) );
		exit;
	}

	/**
	 * Converts the posts and keeps the result for the next page load.
	 *
	 * @param list<int> $ids Post IDs from the confirmed preview.
	 * @return array{dryRun:bool,posts:list<array>,summary:array<string,int>}
	 */
	public static function process( array $ids ): array {
		$report = PostConverter::create()->runMany( $ids, false, static fn( int $id ): bool => current_user_can( 'edit_post', $id ) );
		set_transient( self::REPORT . get_current_user_id(), $report, 10 * MINUTE_IN_SECONDS );
		return $report;
	}

	/**
	 * One table of post reports.
	 *
	 * @param array $report runMany() result.
	 */
	private static function table( array $report ): void {
		?>
		<table class="widefat striped">
			<thead><tr>
				<th><?php esc_html_e( 'Post', 'pediment' ); ?></th>
				<th><?php esc_html_e( 'Type', 'pediment' ); ?></th>
				<th><?php esc_html_e( 'Language', 'pediment' ); ?></th>
				<th><?php esc_html_e( 'Status', 'pediment' ); ?></th>
				<th><?php esc_html_e( 'Legacy blocks', 'pediment' ); ?></th>
				<th><?php esc_html_e( 'Notes', 'pediment' ); ?></th>
			</tr></thead>
			<tbody>
			<?php foreach ( $report['posts'] as $post ) : ?>
				<tr>
					<td><a href="<?php echo esc_url( (string) get_edit_post_link( $post['id'] ) ); ?>"><?php echo esc_html( '' !== $post['title'] ? $post['title'] : '#' . $post['id'] ); ?></a></td>
					<td><?php echo esc_html( $post['type'] ); ?></td>
					<td><?php echo esc_html( $post['language'] ); ?></td>
					<td><?php echo esc_html( $post['status'] ); ?></td>
					<td><?php echo esc_html( implode( ', ', array_merge( $post['converted'], $post['unmapped'] ) ) ); ?></td>
					<td>
						<?php echo esc_html( implode( ' · ', array_merge( $post['errors'], $post['notes'] ) ) ); ?>
						<?php if ( '' !== $post['diff'] ) : ?>
							<details><summary><?php esc_html_e( 'Show changes', 'pediment' ); ?></summary><pre style="white-space:pre-wrap;max-height:30em;overflow:auto"><?php echo esc_html( $post['diff'] ); ?></pre></details>
						<?php endif; ?>
					</td>
				</tr>
			<?php endforeach; ?>
			</tbody>
		</table>
		<p>
		<?php
		$summary = $report['summary'];
		/* translators: 1: posts, 2: legacy blocks, 3: converted, 4: preview, 5: failed, 6: skipped, 7: unchanged */
		echo esc_html( sprintf( __( '%1$d posts, %2$d legacy blocks · converted %3$d · ready %4$d · failed %5$d · skipped %6$d · unchanged %7$d', 'pediment' ), $summary['posts'], $summary['blocks'], $summary['converted'], $summary['preview'], $summary['failed'], $summary['skipped'], $summary['unchanged'] ) );
		?>
		</p>
		<?php
	}
}
```

```php
<?php
/**
 * Converts legacy blocks in a client theme's patterns/*.php files.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Convert;

use Pediment\Content\Policy;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * Rewrites pattern files in place. The leading PHP header is kept byte for
 * byte. Inline PHP (`<?php … ?>`) and seeder media placeholders
 * (`{{media_id:key}}`, `{{media_url:key}}`) are swapped for stand-ins before
 * the block parser sees the file and swapped back afterwards. A file whose
 * inline PHP would not survive the conversion is not written.
 */
final class PatternFiles implements Media {

	private const ID_BASE = 9100000;

	private const URL_BASE = 'https://media.pediment.invalid/';

	/**
	 * Media key per stand-in ID, for the current file.
	 *
	 * @var array<int,string>
	 */
	private array $keys = array();

	/**
	 * Constructor.
	 *
	 * @param Converter $converter Converter.
	 * @param Policy    $policy    Content rules.
	 * @param Media     $media     Lookups for real attachment IDs in a pattern.
	 */
	public function __construct( private Converter $converter, private Policy $policy, private Media $media ) {}

	/**
	 * Converts (or previews) every patterns/*.php file in a directory.
	 *
	 * @param string $dir     Directory that holds the pattern files.
	 * @param bool   $dry_run Preview only.
	 * @return list<array{file:string,status:string,converted:list<string>,blocks:int,unmapped:list<string>,notes:list<string>,errors:list<string>,diff:string}>
	 */
	public function run( string $dir, bool $dry_run ): array {
		$files = glob( rtrim( $dir, '/' ) . '/*.php' );
		$out   = array();
		foreach ( false === $files ? array() : $files as $file ) {
			$text   = (string) file_get_contents( $file ); // phpcs:ignore WordPress.WP.AlternativeFunctions.file_get_contents_file_get_contents -- local theme file.
			$report = $this->convertText( $text );
			$row    = array( 'file' => $file ) + $report;
			unset( $row['text'] );
			if ( 'preview' === $report['status'] && ! $dry_run ) {
				file_put_contents( $file, $report['text'] ); // phpcs:ignore WordPress.WP.AlternativeFunctions.file_system_operations_file_put_contents -- dev-only CLI rewrite of a theme file.
				$row['status'] = 'converted';
				$row['diff']   = '';
			}
			$out[] = $row;
		}
		return $out;
	}

	/**
	 * Converts the text of one pattern file.
	 *
	 * Status: preview (would change; `text` holds the new file), unchanged,
	 * failed (`errors` says why; `text` is the old file).
	 *
	 * @param string $text File contents.
	 * @return array{text:string,status:string,converted:list<string>,blocks:int,unmapped:list<string>,notes:list<string>,errors:list<string>,diff:string}
	 */
	public function convertText( string $text ): array {
		$header = '';
		$body   = $text;
		if ( 1 === preg_match( '/^<\?php.*?\?>\s*/s', $text, $match ) ) {
			$header = $match[0];
			$body   = substr( $text, strlen( $header ) );
		}

		$php        = array();
		$this->keys = array();
		$protected  = (string) preg_replace_callback(
			'/<\?(?:php|=).*?\?>/s',
			static function ( array $m ) use ( &$php ): string {
				$token         = '__PEDIMENT_PHP_' . count( $php ) . '__';
				$php[ $token ] = $m[0];
				return $token;
			},
			$body
		);
		$protected = (string) preg_replace_callback(
			'/\{\{media_(id|url):([a-z0-9_\-\/]+)\}\}/i',
			function ( array $m ): string {
				$id = $this->standIn( $m[2] );
				return 'id' === strtolower( $m[1] ) ? (string) $id : self::URL_BASE . $id . '.jpg';
			},
			$protected
		);

		$result = $this->converter->convert( $protected, $this );
		$names  = array_values( array_unique( $result->converted ) );
		sort( $names );
		$report = array(
			'text'      => $text,
			'status'    => 'unchanged',
			'converted' => $names,
			'blocks'    => count( $result->converted ),
			'unmapped'  => $result->unmapped,
			'notes'     => $result->notes,
			'errors'    => array(),
			'diff'      => '',
		);
		if ( ! $result->changed() ) {
			return $report;
		}

		$errors   = PostConverter::addedErrors( $this->policy->check( $protected )['errors'], $this->policy->check( $result->markup )['errors'] );
		$restored = $result->markup;
		foreach ( $php as $token => $code ) {
			// esc_url() prefixes a bare token with http://.
			$restored = str_replace( 'http://' . $token, $token, $restored );
			if ( 1 !== substr_count( $restored, $token ) ) {
				$errors[] = 'inline PHP ' . $code . ' would not survive the conversion — convert this file by hand';
			}
			$restored = str_replace( $token, $code, $restored );
		}
		foreach ( $this->keys as $id => $key ) {
			$restored = str_replace( self::URL_BASE . $id . '.jpg', '{{media_url:' . $key . '}}', $restored );
			$restored = (string) preg_replace( '/(?<![0-9])' . $id . '(?![0-9])/', '{{media_id:' . $key . '}}', $restored );
		}
		if ( array() !== $errors ) {
			$report['status'] = 'failed';
			$report['errors'] = $errors;
			return $report;
		}
		$report['text']   = $header . $restored;
		$report['status'] = 'preview';
		$report['diff']   = Diff::unified( $text, $report['text'] );
		return $report;
	}

	public function url( int $id, string $size ): string {
		return isset( $this->keys[ $id ] ) ? self::URL_BASE . $id . '.jpg' : $this->media->url( $id, $size );
	}

	public function alt( int $id ): string {
		return isset( $this->keys[ $id ] ) ? '' : $this->media->alt( $id );
	}

	/**
	 * The stand-in ID for a media key (one per key and file).
	 *
	 * @param string $key Media key.
	 */
	private function standIn( string $key ): int {
		$id = array_search( $key, $this->keys, true );
		if ( false === $id ) {
			$id                = self::ID_BASE + count( $this->keys ) + 1;
			$this->keys[ $id ] = $key;
		}
		return (int) $id;
	}
}
```

```php
<?php
/**
 * WP-CLI: `wp pediment convert`.
 *
 * @package Pediment
 */

declare(strict_types=1);

namespace Pediment\Cli;

use Pediment\Content\Policy;
use Pediment\Convert\AttachmentMedia;
use Pediment\Convert\Converter;
use Pediment\Convert\PatternFiles;
use Pediment\Convert\PostConverter;

if ( ! defined( 'ABSPATH' ) ) {
	exit;
}

/**
 * Converts legacy Pediment blocks to core blocks with named styles.
 */
final class ConvertCommand {

	/**
	 * Converts legacy blocks in stored posts, or in a theme's pattern files.
	 *
	 * Without ids, every page, post, synced pattern and template (all
	 * languages) that holds a legacy block is converted. Each converted post
	 * keeps a revision of its old content.
	 *
	 * ## OPTIONS
	 *
	 * [<id>...]
	 * : Only these post IDs.
	 *
	 * [--dry-run]
	 * : Show what would change; write nothing.
	 *
	 * [--patterns=<dir>]
	 * : Rewrite the *.php pattern files in this directory instead of posts
	 * (dev environments). The PHP header, inline PHP and {{media_id:…}} /
	 * {{media_url:…}} placeholders are kept.
	 *
	 * [--format=<format>]
	 * : Output format.
	 * ---
	 * default: text
	 * options:
	 *   - text
	 *   - json
	 * ---
	 *
	 * ## EXAMPLES
	 *
	 *     wp pediment convert --dry-run
	 *     wp pediment convert 12 14
	 *     wp pediment convert --patterns=wp-content/themes/acme/patterns --dry-run
	 *
	 * @param array<int,string>    $args      Post IDs.
	 * @param array<string,string> $assocArgs Options.
	 */
	public function __invoke( array $args, array $assocArgs ): void {
		$dry_run = (bool) \WP_CLI\Utils\get_flag_value( $assocArgs, 'dry-run', false );
		$json    = 'json' === ( $assocArgs['format'] ?? 'text' );

		if ( isset( $assocArgs['patterns'] ) ) {
			$dir = (string) $assocArgs['patterns'];
			if ( ! is_dir( $dir ) ) {
				\WP_CLI::error( "Not a directory: {$dir}" );
			}
			$rows = ( new PatternFiles( Converter::withDefaults(), new Policy(), new AttachmentMedia() ) )->run( $dir, $dry_run );
			\WP_CLI::log( self::renderPatterns( $rows, $json ) );
			if ( array() !== array_filter( $rows, static fn( array $row ): bool => 'failed' === $row['status'] ) ) {
				\WP_CLI::error( 'Some pattern files were not converted; see above.' );
			}
			return;
		}

		$service = PostConverter::create();
		$ids     = array() === $args ? $service->candidates() : array_map( 'intval', $args );
		$report  = $service->runMany( $ids, $dry_run );
		\WP_CLI::log( self::render( $report, $json ) );
		if ( $report['summary']['failed'] > 0 ) {
			\WP_CLI::error( 'Some posts were not converted; see above.' );
		}
	}

	/**
	 * Text or JSON output for a post run.
	 *
	 * @param array $report PostConverter::runMany() result.
	 * @param bool  $json   JSON output.
	 */
	public static function render( array $report, bool $json ): string {
		if ( $json ) {
			return (string) wp_json_encode( $report, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE );
		}
		$lines = array();
		foreach ( $report['posts'] as $post ) {
			$lines[] = sprintf( '%-9s %s #%d %s%s', $post['status'], $post['type'], $post['id'], $post['title'], '' !== $post['language'] ? " [{$post['language']}]" : '' );
			foreach ( array_merge( $post['converted'], array_map( static fn( string $name ): string => "{$name} (no mapper, left in place)", $post['unmapped'] ) ) as $name ) {
				$lines[] = "  block: {$name}";
			}
			foreach ( $post['errors'] as $error ) {
				$lines[] = "  error: {$error}";
			}
			foreach ( $post['notes'] as $note ) {
				$lines[] = "  note: {$note}";
			}
			if ( $post['restoreRevision'] > 0 ) {
				$lines[] = "  old content: revision {$post['restoreRevision']}";
			}
			if ( '' !== $post['diff'] ) {
				$lines[] = rtrim( $post['diff'] );
			}
		}
		$s       = $report['summary'];
		$lines[] = sprintf( '%d posts, %d legacy blocks: %d converted, %d to convert, %d unchanged, %d failed, %d skipped.', $s['posts'], $s['blocks'], $s['converted'], $s['preview'], $s['unchanged'], $s['failed'], $s['skipped'] );
		return implode( "\n", $lines );
	}

	/**
	 * Text or JSON output for a pattern run.
	 *
	 * @param list<array> $rows PatternFiles::run() result.
	 * @param bool        $json JSON output.
	 */
	public static function renderPatterns( array $rows, bool $json ): string {
		if ( $json ) {
			return (string) wp_json_encode( $rows, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE );
		}
		$lines = array();
		foreach ( $rows as $row ) {
			$lines[] = sprintf( '%-9s %s', $row['status'], $row['file'] );
			foreach ( $row['errors'] as $error ) {
				$lines[] = "  error: {$error}";
			}
			foreach ( $row['notes'] as $note ) {
				$lines[] = "  note: {$note}";
			}
			if ( '' !== $row['diff'] ) {
				$lines[] = rtrim( $row['diff'] );
			}
		}
		return implode( "\n", $lines );
	}
}
```

```php
 * @package Pediment

/**
 * Legacy blocks keep rendering and editing; they only leave the inserter, so
 * nobody adds new ones. No block.json is edited.

final class LegacyBlocks {

	/**
	 * Hooks the filter (before blocks register on init).
	 */
	public static function register(): void {
		add_filter( 'register_block_type_args', array( self::class, 'hide' ), 10, 2 );
	}

	/**
	 * Sets supports.inserter = false on legacy blocks.
	 *
	 * @param array  $args Block type args.
	 * @param string $name Block name.

	public static function hide( array $args, string $name ): array {
		if ( in_array( $name, Policy::LEGACY, true ) ) {
			$args['supports']             = (array) ( $args['supports'] ?? array() );
			$args['supports']['inserter'] = false;
		}
		return $args;
	}
}
```

```markdown
# Converting legacy blocks

Pediment 4 replaces 18 presentation blocks (`pediment/hero`, `cta`,
`feature-grid`, `faq` and the others in `Policy::LEGACY`) with core blocks and
named styles. The converter rewrites stored content. The legacy blocks still
render, but the block inserter no longer offers them, and Pediment 5 deletes
them.

## What the converter does

Each legacy block becomes a fixed tree of core blocks that uses the plugin's
default styles (see [design-layer.md](design-layer.md)):

| Legacy block | Becomes |
| --- | --- |
| `section-head` | constrained group (preset bottom margin) → `eyebrow` paragraph, heading, `lead` paragraph |
| `hero` default / centered | section group → h1, `lead` paragraph, `pill` button |
| `hero` media-bg | `media-card` cover (the image, primary overlay) → h1, `lead`, `pill` button |
| `hero` stat-card | columns: copy, `pill` + `pill-ghost` buttons, ticks list · `media-card` cover with a `card` group that holds a `stat` group and the metrics |
| `cta` | `panel` section group → h2, paragraph, `pill` + `pill-ghost` buttons |
| `feature-grid` + `feature` | grid group (3 columns, 2 for four cards) of `card` groups → image, h3, text, link |
| `stat-grid` + `stat` | grid group of `stat` groups → value, label, context |
| `steps` + `step` | `steps` grid group (numbers the steps) of groups → h3, text |
| `media-text` | `media-row` media & text block; inner blocks move unchanged |
| `testimonial-grid` + `testimonial` | 2-column grid of `quote-card` groups → quote with the byline, or a rounded avatar and byline |
| `logo-cloud` | `logos` section group → caption, a wrapping row with the logo images |
| `pull-quote` | `pull-quote` quote |
| `image-caption` | `framed` image with its caption |
| `prose` | `prose` constrained group; inner blocks move unchanged |
| `faq` + `faq-item` | vertical group of `accordion` details blocks |

A child block outside its parent (a lone FAQ item, stat, step, feature or
testimonial) converts on its own. A legacy block inside another block, at any
depth, converts too. A block that rendered nothing (a FAQ item without
question and answer, an image caption whose image is gone) is removed.

Some things have no core equivalent and are dropped. The report names each one:

- Feature icons, hero tick icons and the FAQ toggle icon. A feature with an
  image keeps the image.
- Hover effects (card lift, link arrow).
- `maxWidth` of a section head.
- An `is-style-*` class on a legacy block that is not registered for the new
  block ("dropped style is-style-align-center on pediment/feature → core/group").
  A client theme can register that style for the new block before the
  conversion; then the class stays.

Plain classes (for example `guide-cards`), the list-view name and the block
lock move to the new outer block. A client theme that styled the legacy
`starter-*` classes needs matching styles for the new blocks.

## Run it

Always preview first. The preview shows every post that holds a legacy block
and a line diff of the change. Nothing is written until you confirm.

- **wp-admin** (production): Settings → Pediment Theme → **Convert legacy
  blocks**. The tab lists the preview. **Convert N posts** converts the
  previewed posts. You need the `manage_options` and `edit_theme_options`
  capabilities.
- **AI agents**: the `pediment-convert-legacy` MCP tool. `dry_run` is true
  unless the agent sets it to false. See [mcp.md](mcp.md).
- **WP-CLI** (dev environments):

      wp pediment convert --dry-run
      wp pediment convert
      wp pediment convert 12 14 --dry-run
      wp pediment convert --format=json

The converter looks at pages, posts, synced patterns (`wp_block`) and
templates and template parts that are stored in the database, in every
language. It does not change template files in a theme folder.

## Results

Each post gets a status:

| Status | Meaning |
| --- | --- |
| `preview` | Dry run: the post would be converted. |
| `converted` | Written. `restoreRevision` holds the old content. |
| `unchanged` | No legacy block to convert. |
| `failed` | Nothing written. `errors` says why. |
| `skipped` | Not a page, post, synced pattern or template, or you may not edit it. |

A conversion is refused (`failed`) when the new content would break a content
rule that the old content did not break. Example: the text `javascript:` in a
legacy attribute was hidden in the block comment and becomes visible text.
Problems that were already in the page (`existingErrors`) are reported and
do not stop the conversion.

Before it writes, the converter saves a revision of the current content. To
undo a page, restore `restoreRevision` with `pediment-rollback-page` or the
editor's Revisions screen.

## Pattern files

In a client theme repository, convert the pattern files so that new
environments get the same core blocks as production:

    npx wp-env run cli wp pediment convert --patterns=wp-content/themes/<theme>/patterns --dry-run
    npx wp-env run cli wp pediment convert --patterns=wp-content/themes/<theme>/patterns

The PHP header of each file, inline PHP (`<?php echo … ?>`) and the seeder's
`{{media_id:…}}` and `{{media_url:…}}` placeholders stay as they are. A file
whose inline PHP would be lost (for example PHP that prints a number into a
block attribute) is not written and is listed as `failed`; convert that file
by hand. Run `validate-blocks` on the converted files before you commit.

## For developers

Mappers live in `plugin/src/Convert/Mappers/`, one class per legacy block or
parent/child pair. Each output shape has a fixture pair in
`plugin/tests/phpunit/Convert/fixtures/` (`<name>.input.html` →
`<name>.expected.html`). PHPUnit checks that the converter produces the
expected markup and that it passes the content rules;
`node tools/validate-convert-fixtures.mjs` checks every expected file with
the block validator on WordPress 6.9 and 7.0 (CI job `validator`). The
mappers read parsed markup only, so they keep working after Pediment 5
deletes the legacy block registrations.
```

```markdown

## Limits

- WordPress puts every style's selectors inside `:where()`, so a style has the
  lowest specificity, (0,1,0). A theme rule or a core rule can win over it, and
  a style cannot reliably restyle a nested block that has its own style. Give
  each look to one style on the block that shows it.
- `pediment-upsert-style` replaces the whole `styles` object of a site style.
  To change one property, send the other properties too; read them from
  `pediment-get-vocabulary` first.
- `css` cannot hold media queries. Responsive layout comes from the blocks:
  grid `minimumColumnWidth`, and columns and media & text stack on mobile.
```
