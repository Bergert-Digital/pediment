# Security policy

## Supported versions

Only the latest release of Pediment receives security fixes. Sites update
through the normal wp-admin Updates screen once a fixed release is out.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/Bergert-Digital/pediment/security/advisories/new).

Include the affected version, the steps to reproduce, and the impact you
expect. We confirm the report within five working days, and we tell you when
a fix is released. We credit you in the advisory unless you ask us not to.
